80-scene run

Scenarios in the 80-scene run

What each scenario tests, and how conformal prediction handles it

80 scenes · 1,296 instructions · 7 camera sets · scored before and after a wrist look

Every trial is one scene × one instruction × one set of cameras, scored twice: with the external cameras only, and again after a wrist look. Source document: 80-run-unique-scenario.md; numbers computed by scenarios.py (output scenarios.json).

Setup

Each split calibrates on 18 scenes and tests on 19

Calibration · 18 scenes

Only full-name and absent-box instructions in normal light, one row per scene: 18 rows for Global CP, 54 for the per-count threshold (18 per blocked count).

Output: the threshold. With 18 rows at ε = 0.10 it is the largest calibration score, so it swings between splits: 0.444 to 0.997 for Global CP.

Test · 19 scenes

Every instruction type and camera set: 2,261 decisions per split. Scenes kept out of the split (holdout, duplicate box, physical check, fit, dim, back-light) get the same thresholds.

Output: coverage, set size, actions, wrong grasps. All results in this deck are test results, averaged over 20 random splits.

37 of the 80 scenes can calibrate or test. Every trial was scored once without and once with the wrist image; each context gets its own threshold.

Test population: the test half of each split, i.e. scenes from the standard and absent-box pools, normal light, no holdout scenes, all instruction types. 2,261 is the "all" row's n in the instruction-type table of 80-run-unique-scenario.md.

How to read the tables

Eight numbers per scenario

columnmeaning
top-1share where the model's most probable label is right; no threshold involved
coverageshare where the right label is in the set (target 0.90 at ε = 0.10, 0.80 at ε = 0.20)
setmean labels in the set, out of 5: spots 1–4 and N for “none”
act · ask · abstainshare of decisions: one box → act, two or more labels → ask, {N} or empty → abstain
wrong graspshare of all decisions that grasp a box other than the intended one
look firstshare the decision policy would send to a wrist look as its first move

Defaults: Global CP (one threshold), ε = 0.10, before the look, test scenes, mean of 20 splits. For a missing box the right label is N; for a vague instruction it is the box the speaker meant.

Wrong grasp, in full: for a missing box, any grasp counts as wrong. The source tables also carry n (test decisions per split, mean over 20 splits); the slides drop it as a column and keep it here and in the source.

The source report codes these kinds L0–L4: L0 names a box that is not on the table (absent box, no green box, no small green box), L1 names one box fully (full name), L2 and L3 match two or four boxes (size only, colour only; the box), L4 refers to a box through another one (next to; left of). A missing box is the most dangerous case

25.6%

of decisions grasp some other box when the named box is missing (ε = 0.10)

84.9%

at ε = 0.20

The right answer, N, is in the set only 40.1% of the time. N is the model's top answer 1.1% of the time before the look and 0.0% after it.

The average for missing-box instructions looks fine, 0.956, because 266 of its 296 test rows per split are “green” sentences, which the model handles (0.994, 0.997).

The robot asks on 73.9% of them, about sets of 3.48 labels that usually leave out “none”.

Source: 80-run-unique-scenario.md §1, "What it shows". At ε = 0.20 coverage for the absent box falls to 0.046 with sets of 1.35 labels. The 0.956 average is the L0 coverage reported earlier for all missing-box instructions together.

01 · Instruction types · finding

For vague instructions, loosening ε is unsafe

At ε = 0.10 the robot asks 86–91% of the time on vague instructions, which is the intended move.

At ε = 0.20 it grasps 40–62% of the time on them, and 21–31% of all their decisions grasp the wrong box.

For “the box”, top-1 is 0.245: chance with four candidates.

Ranges come from the six vague rows (size only through left of, other side; L2–L4 in the source) of the ε = 0.20 table in 80-run-unique-scenario.md §1 (act 40.0–62.2%, wrong grasp 20.7–31.0%). Chart: ε = 0.10 open circles, ε = 0.20 filled; the absent-box row is red because it is the failure case.

02 · Camera sets · finding

The look repairs the top camera

Top only: top-1 0.497 → 0.617 after the look, the largest gain; all sets then sit at 0.617–0.648.

At ε = 0.20 without a look, top only grasps the wrong box in 25.0% of decisions; a per-count threshold cuts that to 13.3% by grasping less.

Source: 80-run-unique-scenario.md §2. Per count at ε = 0.20, top only grasps 28.3% of the time against 49.7% under Global CP; it does the same for left only and right only, which did not need it.

Summary

Act on full names; a missing box is the worst case

1

Full-name instructions are the only ones where grasping pays: top-1 0.851, wrong grasps 1.5%.

2

A missing box is the most dangerous case: 25.6% wrong grasps at ε = 0.10, 84.9% at ε = 0.20.

3

Vague instructions should be asked about; loosening ε turns them into 21–31% wrong grasps.

4

The top camera alone is the weakest view, and the wrist look repairs it (0.497 → 0.617).
