“Left of”, “right of” and “in front of” are read in the speaker's frame. Robot side: the speaker stands beside the robot, so both frames agree.

The source report codes these kinds L0–L4: L0 names a box that is not on the table (absent box, no green box, no small green box), L1 names one box fully (full name), L2 and L3 match two or four boxes (size only, colour only; the box), L4 refers to a box through another one (next to; left of). The face uses the plain names only. For “left of, other side”, the right answer is the box on the speaker's left, a side no image shows.
