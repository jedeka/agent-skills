# Routing map (the full table)

Hand a sub-task to the specialist the moment it becomes a discipline; a worse inline
version is never cheaper. Situations, destinations, and hand-back:

| Situation | Route to | Hands back |
|---|---|---|
| Ingest and frame a hard problem from scratch | hypercognize | a structured framing |
| Gather evidence on any topic | deep-research | an evidence map, corroborated |
| Generate candidate ideas or reframes | research-ideation | scored candidate ideas |
| Order candidates, find the cheapest kill test | exploration-triage | an ordered queue |
| "Does this even work" probe | rapid-prototyping | one signal, throwaway code |
| Keep a fast loop honest, decide graduation | honest-iteration | survive/kill verdict |
| Design the decisive test before data exists | experiment-design | a pre-registration block |
| Build correctly (test discipline) | test-driven-development | green suite encoding spec |
| Write/modify the code itself (restraint) | surgical-coding | the minimal diff |
| Diagnose any failure | debug | root cause + fix + regression test hook |
| Read results into a calibrated claim | empirical-analysis | the calibrated claim |
| Something does not fit expectations | anomaly-hunting | artifact-vs-real verdict |
| Attack a claim or the emerging story | red-teaming-research | died/wounded/survived + attack log |
| Invent beyond sources (conjecture) | disciplined-invention | labeled, gated conjecture |
| Any factual assertion, anywhere | grounded-claims | statused, provenanced claims |
| Distill gathered material into knowledge | knowledge-synthesis | durable claims with justification |
| Structure the write-up | organize | the canonical document |
| De-AI and tighten the prose | prose-discipline | final-pass prose |
| Compress for the human | succinct / ultra-summary | MDL text / two-sentence digest |

Precedence notes (where routes could collide):
- honest-iteration governs the *live loop*; empirical-analysis is the *final reading* of a
  pre-registered run. If a pre-registration block exists, empirical-analysis owns the verdict.
- red-teaming-research receives the CLAIM restated alone (fresh context), never the transcript.
- organize structures; knowledge-synthesis decides what is true enough to structure. Synthesis
  before organization when both apply.
- rapid-prototyping suspends surgical-coding's restraint by design; graduation re-imposes it.
